# Agent 运维能力 · Spec

沿用 Agent Runtime Harness 的接口、验签与业务扩展约定。交付五项框架能力：

1. **运行管理**：同步与 SSE 入口继续可用；异步提交持久化后返回 202 和 runId。列表、详情、按 ID 订阅、取消均校验调用方 scope 与 Agent 白名单。状态包含排队、运行、待审批、成功、失败、取消与中断。报告安全的失败原因，以及每轮模型耗时和供应商实际报告的 token 用量。
2. **知识库**：基于配置的共享文档目录，提供索引文档列表、删除索引、重建、检索预览和切片定位。索引变更需要 ingest 权限，管理读取需要 ingest 或 ragRead 权限。删除不改源文件，重建可重新导入。模型在答案里引用检索返回的标记时，输出结构化 citations；拒绝未检索到的标记。
3. **离线评测**：业务工程提供本地 JSON 用例集；CLI 顺序调用实际运行接口，支持多轮、工具、引用、预期 HTTP 拒绝和护栏断言，输出 JSON 报告及 CI 退出码。框架不开放评测 HTTP 端点。
4. **审批及恢复**：声明 approval: required 的能力在执行之前持久化等待审批的调用和图快照；拥有 approve 权限并能访问该运行的调用方可批准或拒绝。恢复继续相同 runId、轮次和工具位置，拒绝作为观察结果返回模型，已完成工具不重跑。待审批快照可以跨进程重启恢复；若运行在执行中断电，不自动重放副作用。Skill 直调无法绕过审批。
5. **有限委派**：Agent 声明可委派的子 Agent，运行以保留工具 agent-delegate 限定目标。子运行有独立 Trace 与线程，不读写父对话记忆，继承 scope 和调用者白名单，父子 Trace 互相关联。限制循环、深度、子运行数和共享模型调用次数；子运行只执行不需要审批的工具，审批工具返回错误，保证委派不会挂起父运行。

参考文件存储为单写进程；后台排队、取消和 SSE 生存周期不依赖外部队列；进程重启后运行中的任务标记为中断，调用方可重新提交。取消会中止支持 AbortSignal 的操作，并阻止后续步骤；外部副作用无法撤回。
